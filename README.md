Ecommerce Spring Boot Project


📌 Project Description

This is a full-stack Ecommerce backend project built using Spring Boot, MySQL, and simple HTML frontend.
It supports full CRUD operations for products and includes a basic UI for interaction.

🚀 Features
Add Product
View Products
Update Product
Delete Product
REST API using Spring Boot
MySQL database integration
Simple interactive frontend (HTML + JS)


🛠️ Tech Stack
Java 17
Spring Boot
Spring Data JPA
MySQL
HTML, CSS, JavaScript
Maven

📂 Project Structure
Controller → API layer
Service → Business logic
Repository → Database access
Entity → Database models
Static → Frontend UI


🔗 API Endpoints
Method	Endpoint	Description
GET	/products	Get all products
GET	/products/{id}	Get product by ID
POST	/products	Add product
PUT	/products/{id}	Update product


DELETE	/products/{id}	Delete product
💻 How to Run Project
mvn spring-boot:run

Then open:
http://localhost:8080/index.html
